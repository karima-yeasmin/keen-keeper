
# Keen Keeper

A web application built with React and Vite.

## Technologies Used

- React
- JavaScript
- Tailwind CSS
- DaisyUI
- React Router

## Getting Started

Clone the repository:

```bash
git clone https://github.com/karima-yeasmin/keen-keeper.git
```

Install dependencies:

```bash
npm install
```

Run the development server:

```bash
npm run dev
```

## Build

```bash
npm run build
```
